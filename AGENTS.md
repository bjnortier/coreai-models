# coreai-models fork

Guidance for agents working in this fork of `apple/coreai-models`. [FORK.md](FORK.md) indexes everything that
differs from upstream; read it before changing anything it covers, and add to it when you diverge further.

## Commits

Don't claim authorship in a commit: no `Co-Authored-By` trailer, or any other line crediting an agent, in a
commit message or pull request description.
